# v1.2.0 发布说明

标签日期：`2026-06-29`

`v1.2.0` 对应 Git commit `758981a`。该版本在 v1.1.0 的多任务与 HTTP 推理基础上，补齐了大规模 DDP 主线、分布式评估/校准、40w 数据证据和更保守的 response serving 默认档。

## 主要变化

- 新增 PyTorch DDP 训练，支持 streaming dataset 按 rank/worker 切分。
- offline eval 与 response calibration 支持分布式执行和 rank 聚合。
- 完成 P800 40w 多任务 v1.1 DDP 训练与 turn/response valid/test 对照。
- 修正 turn discard 等待牌特征和 response 场风役牌路线。
- response calibration 加入 `no_yaku_call_penalty`，报告无明显役路 false call。
- 稳定 Windows/P800 数据集构建 worker，并确保 DDP 各 rank 执行输入校验。
- serving 默认 response 切到 40w `best_response.pt + pass_bias=2.0 + no_yaku_call_penalty=0.8`，优先降低错误鸣牌。

## 当前推荐组合

- turn：`runs/2026-06-24_p800_multitask_v1_1_ddp_40w/multitask/checkpoints/best_turn.pt`
- response：同一 run 的 `best_response.pt`
- response 默认：`pass_bias=2.0`、`no_yaku_call_penalty=0.8`
- 较高召回对照：40w `best_response.pt + pass_bias=0.0 + no_yaku_call_penalty=0.4`
- 历史稳定对照：2026-05-10 improved 单任务 `pass_bias=0.3`

极保守默认档的代价是漏鸣显著增加。正式 valid 扩展扫描中 missed call 约为 `31.52%`，因此它是明确的产品取舍，不代表所有场景下的最优 operating point。

## 关键验证

- 40w 数据：`379742` 场、`385081321` 条事件，事件验证失败 `0`。
- 样本：`185846893` 条 turn、`552934725` 条 response。
- turn `best_turn.pt` test：top1 `72.88%`、top3 `96.04%`、top5 `99.08%`。
- response `best_response.pt` raw test：multi-candidate top1 `87.87%`、non-pass F1 `73.64%`、false call `0.987%`、missed call `8.44%`。

完整对照见 [../multitask-training.md](../multitask-training.md) 第 10 节和 [../status.md](../status.md)。

## 已知限制

- 规则引擎仍不是完整日麻规则与计分实现。
- API 要求调用方传入 `legal_actions`，不会根据 state 重新生成并证明候选合法。
- `replay-eval` 与 `infer-on-state` 仍是占位命令。
- value head/value 训练尚未实现。
- `pass_bias=2.0 + no_yaku_call_penalty=0.8` 明显牺牲召回，必须继续做人工/实战复核。
- 标签版本与包元数据不一致：Git tag 为 `v1.2.0`，但 `pyproject.toml`、`mjai.__version__` 和 OpenAPI 仍报告 `1.1.0`。
